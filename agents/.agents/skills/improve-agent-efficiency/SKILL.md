---
name: improve-agent-efficiency
description: "Audit previous agent sessions and fix what went wrong."
disable-model-invocation: true
---

find and review our recent agent session transcripts.
- discover where agents got stuck or misled
- what did agents already know to do so we can remove it from instructions or docs
- where were agents generally inefficient and what could've led them to the end result quicker
- what tool calls consumed a lot of real world clock time or context window
- where was there more back-and-forth than necessary i.e. the agent could not produce what the human wanted and what would've fixed it
